## Project Description: Campus Connectivity Analyzer

The Campus Connectivity Analyzer is a C++-based application designed to analyze connections between different buildings on a college campus. The user enters the number of buildings, building names, connections between buildings, and selects a starting building.

The system represents the campus network using an Adjacency Matrix and an Adjacency List. It uses Breadth-First Search (BFS) to explore connected buildings level by level and Depth-First Search (DFS) to explore the network by visiting connected buildings recursively. The program displays both graph representations and the traversal results from the user-selected starting building.

### Problem Statement

To develop a campus connectivity analyzer using an adjacency matrix and adjacency list, and apply BFS and DFS algorithms to explore the network from a user-selected building.

### Main Features

1. Accepts building names and connections as user input.
2. Represents the campus network using an adjacency matrix.
3. Stores building connections using an adjacency list.
4. Applies BFS to explore connected buildings level by level.
5. Applies DFS to explore connected buildings recursively.
6. Allows the user to select the starting building.

### Objective

To understand and analyze campus connectivity using graph data structures and traversal algorithms, making it easier to explore connections between different college buildings.
